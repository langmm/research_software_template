# Contributing to myresearchpy

This project follows the [FAIR4RS](https://fair4rs.org) and
[FAIR-CURE](https://doi.org/10.15497/RDA00068) guidelines. Contributions are
expected to preserve those properties; see
[docs/contributing.md](docs/contributing.md) for the full workflow.

## Quick reference

```bash
pixi install
pixi run test         # tests
pixi run lint         # ruff
pixi run docs         # documentation
```

BSD-3-Clause license of this repository.
