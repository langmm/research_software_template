## [0.1.0] - 2026-10-01

### Added

- Initial release of the template package.
- `myresearchpy.energy`: harmonic oscillator spectrum and a variational
  hydrogen ground state estimate.
- `myresearchpy.linalg`: generalised eigenproblem, expectation value and
  normalisation helpers.
- `myresearchpy.utils`: random seeding and environment provenance reporting.
- Sphinx documentation with numpydoc-generated API reference.
- pixi environments for `test`, `docs` and `dev`.
- GitHub Actions workflows for tests, documentation, linting and release.
